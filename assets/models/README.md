# Model vendor marks

These SVGs reproduce the vendor marks that the [Nebius Token Factory model catalog](https://tokenfactory.nebius.com/models/catalog/text2text/zai-org%2FGLM-5.3) shows next to each model. The review footer shows the mark of the vendor whose model ran.

| File | Vendor | Catalog key |
| --- | --- | --- |
| `zai-org.svg` | Z.ai (GLM) | `zaiorg` |
| `moonshotai.svg` | Moonshot AI (Kimi) | `moonshotai` |
| `deepseek-ai.svg` | DeepSeek | `deepseek` |

Source: [official website bundle](https://static.nebius.com/app/ai-studio-ui/210.2df1f04e3ad94d4d.js).
Website version: `ai-studio-ui@1.1314.0+3dbb553b`.

The bundle defines each mark as a React element tree. A static parser converted these trees to SVG; no bundle code was run. The elements, paths, colors, and gradients stay unchanged. Each mark is a 36-pixel square with a white background. The footer displays it at 20 pixels high.

These marks belong to their vendors.
