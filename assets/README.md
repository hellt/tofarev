# Token Factory logo

These SVGs reproduce the header logo from [Nebius Token Factory](https://tokenfactory.nebius.com).

Source: [official website bundle](https://static.nebius.com/app/ai-studio-ui/6049.20e24ae791795f9a.js).
Website version: `ai-studio-ui@1.1238.0+278a6a38`.

The vectors, colors, and gradients stay unchanged.
A `viewBox` preserves scaling from the original 28-pixel height.
The footer displays the logo at 22 pixels high.

The `light` variant matches light backgrounds.
The `dark` variant matches dark backgrounds.
